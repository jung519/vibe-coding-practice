# 요약: 이 폴더의 파일 규칙(4원칙)과 참조 방법

## 좋은 Knowledge 파일 4원칙 (교재 그림 기반 정리)
1. **한 파일 한 주제** — 파일명만 보고 내용을 알 수 있게 (예: 경쟁사_분석.md)
2. **맨 위 3줄 메타데이터** — `# 파일명(출처)` / `# 갱신일` / `# 요약 한 줄`
3. **출처·검증 상태 표기** — 어느 산출물(관리번호)에서 왔는지, 사실/가설 구분
4. **갱신일 관리** — 내용이 바뀌면 갱신일을 올리고 원본 관리번호를 남긴다

## 참조 방법 (준-RAG)
"knowledge 폴더를 참고해서 ○○ 알려줘"라고 물으면 AI가 이 폴더를 읽고 답한다.
서버·데이터베이스 없이 폴더 하나로 내 자료를 참고하게 만드는 방법.
