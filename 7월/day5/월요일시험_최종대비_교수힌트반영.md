# 월요일 시험 최종 대비 — 교수 힌트 반영판

> 새 힌트: ① 수학 계산 없음, 개념 위주 ② 예시: "여러 레이어의 gradient 계산 방법?" → Backpropagation
> ③ 예시: 텐서 shape 행렬곱 (32×16 @ 16×8 → 32×8) ④ 핵심 키워드: gradient descent 원리, **Adam**
> 반영 사항: 파이토치 출제 확정, shape 문제 유형 추가, Adam 보충 설명 추가.

---

## 1. Shape 문제 — 규칙 하나면 끝 (개발자에게 제일 쉬운 유형)

교수 예시가 "32×16 @ 16×8 → 32×8"입니다. 규칙은 딱 하나:

**(n × m) @ (m × p) = (n × p) — 가운데 두 숫자(m, m)가 같아야 곱할 수 있고, 결과는 바깥 두 숫자(n, p).**

배열 다루듯 생각하면 됩니다: 안쪽이 맞물리고, 바깥이 살아남는다.

연습 (답 바로 아래):
- (a) 64×32 @ 32×10 → ?
- (b) 128×784 @ 784×14 → ?
- (c) 32×16 @ 8×16 → ?
- (d) 1×512 @ 512×512 → ?

답: (a) **64×10** (b) **128×14** (c) **곱셈 불가!** (가운데가 16 vs 8로 다름 — 이런 함정 보기가 나올 수 있음) (d) **1×512**

실전 팁: 보기에서 "가운데 숫자가 안 맞는데 결과가 있는 척하는" 선택지를 먼저 지우면 됩니다.

## 2. 교수 예시 유형 그대로 — 개념 이름 고르기

**Q. 여러 레이어로 구성된 신경망에서 각 파라미터의 gradient를 계산하는 방법은?**
→ **Backpropagation** (chain rule을 출력→입력 방향으로 반복 적용)

같은 패턴의 변형들:
- 입력→출력 방향으로 계산을 진행하는 과정은? → **Forward propagation**
-    알고리즘은? → **Gradient descent**
- 한 번에 이동하는 보폭을 정하는 값은? → **Learning rate**
- 파라미터 갱신 방향은? → **Gradient의 반대 방향**

## 3. Adam — 5일차 키워드 보충 (2분 설명)

Gradient descent의 개량판 계보만 알면 됩니다. 전부 "안개 낀 산 내려가기"의 요령입니다:

- **기본 Gradient descent**: 매 걸음 그 자리의 경사만 보고 이동. 단순하지만 지그재그로 헤매거나 얕은 웅덩이에 빠질 수 있음.
- **Momentum(관성)**: 굴러가는 공처럼 지금까지 가던 방향의 관성을 유지. 잔 지그재그가 줄고 얕은 웅덩이를 관성으로 통과.
- **AdaGrad / RMSProp(적응형 보폭)**: 파라미터마다 보폭을 다르게 자동 조절. 많이 움직였던 방향은 보폭을 줄이고, 덜 움직인 방향은 크게.
- **Adam** = **Momentum + 적응형 보폭을 합친 것.** 그래서 실무 기본값("그냥 Adam 쓰세요").

예상 문제:
- "Momentum과 adaptive learning rate를 결합한 optimizer는?" → **Adam**
- "Adam이 결합한 두 아이디어는?" → **관성(momentum) + 파라미터별 보폭 자동 조절**
- "가장 널리 쓰이는 기본 optimizer는?" → **Adam**

## 4. PyTorch — 출제 확정이니 이 7개만

4일차 정리에서 시험에 나올 만한 것만 압축:

| 질문                                   | 답                       |
| ------------------------------------ | ----------------------- |
| 딥러닝 모델의 기본 연산 단위(입력·출력·파라미터 모두 이것)는? | **Tensor**              |
| gradient 자동 계산을 켜는 속성은?              | **requires_grad=True**  |
| gradient 계산(backprop)을 실행하는 코드는?     | **loss.backward()**     |
| 파라미터를 실제로 갱신하는 코드는?                  | **optimizer.step()**    |
| gradient 누적을 막기 위해 매번 호출하는 것은?       | **zero_grad()**         |
| 텐서를 GPU로 옮기는 코드는?                    | **x.to("cuda")**        |
| 행렬곱 함수는? (원소별 곱과 구분)                 | **torch.mm** (원소별은 mul) |

backward / step / zero_grad **세 개의 역할 구분**이 가장 나올 법한 포인트입니다:
**backward = 방향 계산, step = 이동, zero_grad = 장부 초기화.** (매 반복: zero_grad → forward → loss → backward → step)

## 5. 최종 암기 리스트 (이전 11줄 + 오늘 4줄 = 이것만 보고 입장)

**기존 핵심**
1. -log(정답 자리의 확률) = cross entropy = softmax loss = NLL
2. D_KL = CE − H(P). KL은 비대칭, 0 이상, P=Q일 때만 0, q=0인데 일어나면 무한대
3. Entropy: 균등 최대, 정해져 있으면 0, 단위 bit. 독립이면 H(X,Y)=H(X)+H(Y)
4. Gradient = 최속 증가 방향 → 갱신은 반대 방향, 보폭 = learning rate
5. 퍼셉트론 = 선형 분류기 → XOR 불가 → MLP로 해결. 활성화 함수 없으면 층 쌓아도 선형
6. Softmax = logit을 합 1 확률로(순서 보존). FC layer = Linear layer. MNIST 28×28
7. Backprop: downstream = local × upstream. 덧셈 = 분배, 곱셈 = 상대값, max = 승자 독식. 갱신 대상은 가중치만

**오늘 추가**
8. **여러 레이어의 gradient 계산 = Backpropagation** (교수가 예시로 낸 그대로)
9. **Shape: (n×m)@(m×p)=(n×p), 가운데 맞물리고 바깥이 남는다**
10. **Adam = Momentum(관성) + 적응형 보폭. 실무 기본 optimizer**
11. **파이토치: backward=방향 계산, step=이동, zero_grad=초기화. 기본 단위는 Tensor**
