# 파이토치 API 명세서 — 5~10일차 등장 함수 전부

> 개발자용 인터페이스 문서 형식: 시그니처 → 인자 의미 → 출력 규칙 → 예제.
> 출제 가능성: 🔴 높음(shape 예측·동작 구분 문제로 내기 좋음) / 🟡 중간 / ⚪ 낮음(실습 디테일).
> 내부 구현은 몰라도 됩니다. 입출력 계약만 보면 됩니다.

---

## 1. 층(Layer) — shape 문제의 주인공들

### `nn.Conv2d(in_channels, out_channels, kernel_size, stride=1, padding=0)` 🔴 최고 순위
- **하는 일**: 이미지에 필터(도장) 여러 개를 밀며 찍어 특징 지도를 만듦
- **인자**: 입력채널(입력 텐서 2번째 숫자와 일치해야 함) / 출력채널(=필터 개수) / 도장 크기 / 이동 보폭 / 테두리 0 두께
- **출력 규칙 (3단계)**: ① 장수(batch) 그대로 ② 채널 → out_channels로 교체 ③ 크기: padding=(k−1)/2이면 유지, stride=2면 절반
- **예**: (16, 3, 32, 32) + Conv2d(3, 64, 3, stride=1, padding=1) → **(16, 64, 32, 32)**
- **예**: (16, 3, 32, 32) + Conv2d(3, 64, 3, stride=2, padding=1) → **(16, 64, 16, 16)**

### `nn.MaxPool2d(kernel_size)` 🔴
- **하는 일**: 구역(보통 2×2)마다 최댓값만 남겨 해상도를 줄임
- **출력 규칙**: 장수·채널 그대로, **크기만 1/kernel_size** (2면 절반). 학습 파라미터 없음
- **예**: (1, 64, 8, 8) + MaxPool2d(2) → **(1, 64, 4, 4)**

### `nn.Linear(in_features, out_features)` 🔴
- **하는 일**: 행렬곱 층 (FC layer). 벡터 길이를 in → out으로 변환
- **출력 규칙**: 마지막 차원만 in_features → out_features로 교체. in_features는 입력 마지막 숫자와 일치해야 함
- **예**: (64, 784) + Linear(784, 32) → **(64, 32)**

### `nn.ReLU()` / `nn.Sigmoid()` / `nn.Tanh()` / `nn.LeakyReLU()` 🟡
- **하는 일**: 구부리는 함수(활성화). 원소별 적용이라 **shape 안 변함**
- **구분 포인트**(개념 문제로 출제): Sigmoid 출력 0~1(gradient 소실 있음) / Tanh −1~1(평균 0, 소실 여전) / ReLU 음수→0(표준, Dead ReLU 약점) / LeakyReLU(음수에도 작은 기울기 = Dead ReLU 보완)

### `nn.BatchNorm2d(num_features)` 🟡
- **하는 일**: 배치 단위로 평균 0, 분산 1로 표준화 (+학습되는 γ, β). num_features = 채널 수
- **출력 규칙**: shape 안 변함
- **함정 포인트**: 학습 시엔 배치 통계, 추론 시엔 이동평균 사용 → train/eval 모드 구분 필요 (아래 참조)

### `nn.Dropout(p)` 🟡
- **하는 일**: 학습 중 확률적으로 뉴런 출력을 0으로 (p=끌 확률). shape 안 변함
- **함정 포인트**: 추론 시엔 **모든 뉴런 사용** (동작 자체가 꺼짐)

### `nn.Sequential(층1, 층2, ...)` ⚪
- **하는 일**: 층들을 순서대로 묶어 하나처럼 실행. 결과는 개별 선언과 동일

### `nn.Embedding(vocab_size, dim)` ⚪ (9~10일차)
- **하는 일**: 단어 번호(정수)를 벡터로 변환하는 조회 테이블. 언어 모델의 입구

### `nn.LSTM(input_size, hidden_size)` / `nn.GRU(...)` ⚪
- **하는 일**: 순서 데이터용 층. 코드 shape 문제보다는 개념(cell state, 게이트)으로 출제될 것

## 2. 학습 루프 — 순서·역할 구분 문제의 주인공들

### 학습 루프 5종 세트 🔴 (순서 문제로 출제 확률 최고)
```python
optimizer.zero_grad()   # ① gradient 장부 초기화 (누적 방지)
outputs = model(x)      # ② forward (예측)
loss = criterion(outputs, y)  # ③ 오답 점수 계산
loss.backward()         # ④ backward (gradient 계산)
optimizer.step()        # ⑤ 파라미터 갱신 (실제 이동)
```
- **함정 포인트**: backward는 "계산만", step이 "이동". zero_grad 빼먹으면 gradient 누적됨

### `optim.Adam(model.parameters(), lr=0.001, betas=(0.9, 0.999))` 🔴
- **하는 일**: 실무 기본 optimizer. **Momentum + RMSProp** 결합 (+초기 편향 보정)
- **인자**: lr=보폭(learning rate), betas=(momentum 계수, RMSProp 계수)

### `optim.SGD(model.parameters(), lr=0.01)` 🟡
- **하는 일**: 기본 gradient descent. Adam과의 비교(느림 vs 빠름)로 출제 가능

### `nn.CrossEntropyLoss()` 🔴
- **하는 일**: 분류용 오답 점수판 (softmax + -log(정답 확률)을 한 번에)
- **개념 연결**: "분류 태스크의 loss는?" → Cross Entropy (지난 시험 Q10 그대로)
- ⚪ 옵션 `ignore_index=pad`: 패딩 토큰은 채점 제외 (언어 모델용 디테일)

### `model.train()` / `model.eval()` 🔴
- **하는 일**: 학습/추론 모드 전환
- **핵심**: 영향받는 층은 **Dropout과 BatchNorm 둘뿐** (다른 층은 동일 동작). "eval()시 동작이 바뀌는 층은?"으로 출제하기 좋음

## 3. 데이터 — 역할 매칭 문제 후보

### `Dataset` 클래스 (상속 구현) 🟡
- **필수 구현 함수 3개**: `__init__`(경로 준비) / `__len__`(총 개수) / `__getitem__`(index번째 데이터 1개 반환)
- **출제 형태**: "Dataset 클래스에 필수로 구현해야 하는 함수가 아닌 것은?"

### `DataLoader(dataset, batch_size, shuffle, drop_last)` 🔴
- **하는 일**: 데이터를 배치 단위로 묶어 공급하는 컨베이어 벨트
- **인자**: batch_size=한 번에 몇 개 / shuffle=True면 순서 섞기(정렬된 데이터의 가짜 패턴 학습 방지 — 학습용 필수) / drop_last=True면 자투리 배치 버림
- **계산 출제 가능**: 60000장 ÷ batch 64 = 937.5 → drop_last=True면 **937**, False면 938

### `torchvision.transforms` (RandomCrop, RandomHorizontalFlip, RandomRotation, ToTensor, Normalize) 🟡
- **하는 일**: 데이터 증강 파이프라인. "Random~ 계열 = data augmentation"이라는 매칭만 알면 됨

## 4. 텐서 조작 — 1주차 유형이지만 재출제 가능

### `torch.mm(x1, x2)` 🔴 (지난 시험 기출)
- **규칙**: (a×b)@(b×c) → 가운데 맞물려 소멸 → **(a×c)**. 가운데 다르면 에러

### `tensor.reshape(-1, k)` 🟡 (기출)
- **규칙**: −1 = "나머지는 알아서". 전체 원소 수 ÷ k가 −1 자리에 들어감

### `torch.cat((x, y), dim)` 🟡 (기출)
- **규칙**: 지정한 dim 방향으로 이어 붙임. dim=0 세로(행 증가), dim=1 가로(열 증가)

### `tensor.squeeze()` / `unsqueeze(dim)` ⚪
- **규칙**: 크기 1인 차원 제거 / dim 위치에 크기 1 차원 추가

## 5. 저장/장치 — 한 줄씩만

### `torch.save(model.state_dict(), 'model.pt')` 🟡
- **하는 일**: **가중치 딕셔너리**를 파일로 저장 (모델 파일의 정체 = 숫자 뭉치). 복원은 `model.load_state_dict(torch.load(...))`

### `model.to('cuda')` / `x.to('cuda')` 🟡
- **하는 일**: 모델/텐서를 GPU로 이동. **모델과 입력 둘 다** 옮겨야 함 (한쪽만 옮기면 에러 — 함정 출제 가능)

### `torch.cuda.is_available()` ⚪
- **하는 일**: GPU 사용 가능 여부 확인 (True/False)
