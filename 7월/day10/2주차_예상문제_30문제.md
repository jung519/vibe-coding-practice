**11.** Dropout(p=0.5)을 적용한 모델의 추론(테스트) 시 동작은?

## 정답 및 해설

**A파트 (코드 유형)**
1. **①** — padding=1, stride=1, k=3이면 크기 유지. 채널만 3→64. (규칙: p=(k−1)/2면 크기 보존)
2. **②** — stride=2면 해상도 절반(32→16), 채널은 out_channels(32).
3. **③** — h−k+1 = 9−3+1 = 7.
4. **①** — MaxPool2d(2)는 해상도만 절반(8→4), 채널 불변.
5. **②** — p=(k−1)/2 = (3−1)/2 = 1.
6. **①** — zero_grad(장부 초기화) → loss 계산 → backward(방향 계산) → step(이동). ※forward는 loss 계산 전에 이미 수행.
7. **①** — Adam = Momentum + RMSProp (+ 초기 편향 보정). betas의 0.9가 momentum 쪽, 0.999가 RMSProp 쪽 계수.
8. **①** — Dropout(추론 시 전부 켬)과 BatchNorm(추론 시 이동평균 사용)만 train/eval에 따라 동작이 바뀜.
9. **①** — state_dict = 가중치 딕셔너리. 모델 파일(.pt)의 정체.
10. **①** — 정렬된 데이터로 학습하면 라벨 순서라는 가짜 패턴을 학습함 (노트북에서 실험으로 시연됨).
11. **①** — 추론 땐 전부 사용. 크기 보정은 inverted dropout으로 학습 때 미리 처리.
12. **①** — 937.5에서 자투리 배치를 버리므로(drop_last=True) 937. False면 938.

**B파트 (개념)**
13. **①** Epoch.
14. **①** 발산/진동. 너무 작으면 느림.
15. **①** Momentum. 부작용은 overshooting, 개선판 Nesterov.
16. **①** RMSProp — 누적합 대신 이동평균 ("Leaky AdaGrad").
17. **①** Dead ReLU.
18. **①** — 위치는 선형층 뒤·활성화 앞. 추론 시엔 이동평균 사용.
19. **①** Mixup. Cutout=가리기, CutMix=조각 교체(라벨은 면적 비율).
20. **①** — 클래스 불균형 → Accuracy 왜곡 → Precision/Recall 필요.
21. **①** Recall = TP/(TP+FN). Precision은 "양성이라 말한 것 중 진짜" = TP/(TP+FP).
22. **①** 0.5. 완벽하면 1.
23. **①** Micro — 전체를 합산해서 계산하므로 다수 클래스가 지배. Macro는 클래스 동등.
24. **①** 표 데이터 — 인접성에 의미가 없으므로. CNN은 인접 feature가 관련 있는 데이터용.
25. **①** — 반복 곱셈의 복리 효과. |값|<1이면 vanishing, >1이면 exploding.
26. **①** Cell state — 덧셈 기반 고속도로. 관리자는 forget/input/output 게이트.
27. **①** Bottleneck — Attention이 해결.
28. **①** — Attention은 오히려 파라미터가 늘어남(실습에서 1,390만→2,050만). 나머지 셋이 진짜 장점.

**C파트 (OX)**
29. **True** — 증가 방향이 맞음. (실제 시험 Q6은 "감소 방향"이라고 해서 False였음 — 방향 단어를 끝까지 읽을 것!)
30-a. **True** — pooling은 최댓값 고르기만 하므로 학습 파라미터 없음.
30-b. **False** — 모든 time step에서 같은 파라미터를 공유.
30-c. **True** — 틀린 예측이 뒤를 전부 망치는 걸 막는 기법.

## 시험 직전 정리 — A파트용 규칙 5개 (이것만 외우면 코드 유형 전부 풀림)

1. **conv 채널**: 출력 채널 = out_channels (필터 개수). 입력 채널은 사라짐.
2. **conv 크기**: padding 없으면 h−k+1. p=(k−1)/2면 크기 유지. **stride=2면 절반.**
3. **pooling**: 해상도만 절반, 채널 불변, 파라미터 없음.
4. **학습 루프 주문**: zero_grad → forward → loss → backward → step.
5. **train/eval 구분 대상은 Dropout과 BatchNorm 둘뿐.**
