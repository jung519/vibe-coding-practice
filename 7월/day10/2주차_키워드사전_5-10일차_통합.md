# 5일차 — Gradient Descent 변형들과 Activation

### Gradient Descent (경사하강법, GD)
- 정의: 오답 점수(loss)가 낮아지는 방향(gradient의 **반대** 방향)으로 파라미터를 조금씩 갱신하는 알고리즘. 갱신식: 새 값 = 옛 값 − learning rate × gradient
- 시험 포인트: 방향은 gradient의 **반대**. 한 번 이동 = step(또는 iteration)
- 관련: Learning rate, SGD, Adam

### SGD (Stochastic Gradient Descent, 확률적 경사하강법)
- 정의: 전체 데이터 대신 **샘플 1개**로 gradient를 계산해 갱신. 빠르지만 방향이 부정확해 지그재그로 수렴
- 시험 포인트: "전체 데이터(정확·느림) vs 샘플 1개(부정확·빠름)"의 대비. 파이토치 코드는 optim.SGD
- 관련: Mini-batch, Gradient Descent

### Mini-batch (미니배치)
- 정의: 데이터를 일부 묶음(batch) 단위로 잘라 gradient를 계산하는 방식. **실전에서 가장 많이 사용**
- 시험 포인트: batch size는 보통 2의 배수(64, 128, 256). **batch가 클수록 gradient 분산이 작아져 학습이 안정적**이고 더 낮은 loss에 도달
- 관련: Batch size, Epoch, DataLoader

### Epoch (에폭)
- 정의: **전체 데이터셋을 한 바퀴 모두 순회**한 것. "10 epoch 학습" = 전체 데이터를 10번 봄
- 시험 포인트: 용어 정의 그대로 출제되기 좋음
- 관련: Mini-batch, Batch size

### Learning rate (학습률, α)
- 정의: 한 번 갱신할 때의 보폭. 갱신식에서 gradient에 곱해지는 값
- 시험 포인트: **너무 크면 발산(loss 증가/진동), 너무 작으면 수렴이 매우 느림**. 최적값은 상황마다 다름
- 관련: Learning rate scheduling, Gradient Descent

### Learning rate scheduling (학습률 스케줄링, decay)
- 정의: 학습이 진행될수록 learning rate를 점점 **줄여가는** 기법. "처음엔 크게, 나중엔 작게"
- 시험 포인트: 3가지 방법 — **Step decay**(정해진 epoch마다 절반씩), **Exponential decay**(지수적으로 감소), **1/t decay**(분수 함수로 감소)
- 관련: Learning rate

### Momentum (모멘텀)
- 정의: 현재 gradient만 쓰지 않고 **과거 gradient를 축적(관성)**해서 이동하는 GD 변형. 계수는 보통 0.9 또는 0.99
- 시험 포인트: 장점 = **local minimum(얕은 웅덩이) 탈출** 가능. 단점 = **overshooting**(목표를 지나침)
- 관련: Nesterov, Adam, Local minimum

### Nesterov Momentum (네스테로프 모멘텀)
- 정의: 관성 방향으로 **미리 이동해본 위치에서** gradient를 계산하는 momentum 개선판
- 시험 포인트: "미리 이동 후 gradient 계산" → overshooting 감소, 수렴 속도 개선
- 관련: Momentum, Overshooting

### Overshooting (오버슈팅)
- 정의: 관성이 세서 최저점(global minimum)을 지나쳐 버리는 현상. momentum의 부작용
- 관련: Momentum, Nesterov

### Local minimum (로컬 미니멈, 지역 최저점)
- 정의: 주변보다는 낮지만 전체 최저점(global minimum)은 아닌 얕은 웅덩이. 기본 GD는 여기 갇힐 수 있음
- 시험 포인트: **Momentum이 관성으로 탈출**시켜 줌
- 관련: Momentum

### AdaGrad (아다그라드)
- 정의: 파라미터(차원)마다 learning rate를 다르게 주는 방법. 과거 gradient 제곱의 **누적합**이 컸던 차원은 보폭을 줄임
- 시험 포인트: 핵심 용어 = **Per-parameter learning rate / Adaptive learning rate**. 단점 = 누적합이 계속 커져서 **학습 후반에 보폭이 0에 가까워짐**
- 관련: RMSProp, Adam, Adaptive learning rate

### Adaptive learning rate (적응형 학습률)
- 정의: 파라미터별로 learning rate를 자동 조절하는 방식의 총칭 (AdaGrad, RMSProp, Adam이 이 계열)
- 관련: AdaGrad, RMSProp, Adam

### RMSProp (알엠에스프롭)
- 정의: AdaGrad의 개선판. 누적합 대신 **이동평균(moving average)**을 써서 보폭이 영영 쪼그라드는 문제를 해결. 별명 "Leaky AdaGrad"
- 시험 포인트: "AdaGrad의 후반 학습 정지 문제를 이동평균으로 해결한 것은?" → RMSProp
- 관련: AdaGrad, Adam

### Adam (아담)
- 정의: **Momentum + RMSProp을 결합**하고 **초기 편향 보정(bias correction)**을 더한 optimizer. **실전에서 가장 널리 사용(기본값)**
- 시험 포인트: 조합 공식 "Adam = Momentum + RMSProp" 최다 출제 후보. 코드: optim.Adam(model.parameters(), lr=0.001, betas=(0.9, 0.999))
- 관련: Momentum, RMSProp

### 초기 편향 보정 (Bias Correction)
- 정의: 이동평균을 0에서 시작하면 초반 값이 실제보다 작게(0 쪽으로) 치우치는 문제를 나누기로 바로잡는 것. Adam의 세 번째 구성 요소
- 관련: Adam

### Sigmoid (시그모이드)
- 정의: 어떤 실수든 **0~1 사이**로 눌러주는 S자 활성화 함수
- 시험 포인트: 문제점 3개 — ① 포화 구간에서 **gradient 소실** ② 출력 평균이 0이 아님(항상 양수) ③ 지수 계산이 느림
- 관련: Tanh, ReLU, Vanishing gradient

### Tanh (탄젠트하이퍼볼릭)
- 정의: 어떤 실수든 **−1~1 사이**로 눌러주는 S자 활성화 함수
- 시험 포인트: 장점 = **출력 평균이 0** (sigmoid의 문제 ② 해결). 단점 = 포화 시 gradient 소실은 **여전함**
- 관련: Sigmoid, ReLU

### ReLU (렐루)
- 정의: 음수는 0으로, 양수는 그대로 통과시키는 활성화 함수. **현재 표준**
- 시험 포인트: 장점 = 양수 구간에서 포화 없음, 계산이 매우 빠름(수렴 약 6배 빠름). 단점 = 출력 평균이 0 아님, 음수 구간 기울기 0 → **Dead ReLU** 위험
- 관련: Dead ReLU, LeakyReLU, Sigmoid

### Dead ReLU (죽은 렐루)
- 정의: 어떤 뉴런의 선형 출력이 **모든 데이터에 대해 음수**가 되어, 출력도 0·gradient도 0 → **영원히 학습되지 않는 뉴런**
- 시험 포인트: "ReLU가 항상 gradient 소실을 해결하는 것은 아니다"의 근거
- 관련: ReLU, LeakyReLU

### Dataset (데이터셋 클래스)
- 정의: "데이터 한 개를 어떻게 읽을지"의 규칙을 담는 파이토치 클래스
- 시험 포인트: **필수 구현 함수 3개** — `__init__`(경로 준비), `__len__`(총 개수), `__getitem__`(index번째 데이터 반환)
- 관련: DataLoader

### DataLoader (데이터로더)
- 정의: Dataset을 batch 단위로 묶어 공급하는 장치
- 시험 포인트: 주요 인자 — **batch_size**(한 번에 몇 개), **shuffle=True**(순서 섞기: 데이터가 라벨 순으로 정렬돼 있으면 잘못된 패턴을 학습하므로 학습용은 필수), **drop_last=True**(자투리 배치 버림: 60000÷64=937.5 → 937 배치)
- 관련: Dataset, Mini-batch

### nn.Module / forward (모델 클래스)
- 정의: 파이토치 모델의 표준 틀. `__init__`에 층 선언, `forward`에 계산 순서 정의. 객체를 호출하면(`model(x)`) forward가 자동 실행
- 관련: 학습 루프

### state_dict (모델 저장/로드)
- 정의: 모델의 **가중치(파라미터) 값들을 담은 딕셔너리**. `torch.save(model.state_dict(), 'model.pt')`로 저장, `load_state_dict`로 복원
- 시험 포인트: 모델 파일(.pt)의 정체 = 가중치 숫자 뭉치. 로드한 모델은 원본과 완전히 같은 출력을 냄
- 관련: nn.Module

# 6일차 — 과적합 방지

### Overfitting (과적합)
- 정의: 모델이 **훈련 데이터는 잘 맞추는데 새(테스트) 데이터에서 실패**하는 상태. 훈련 데이터를 암기해버린 것
- 시험 포인트: 원인 = 데이터 대비 모델이 너무 큼(파라미터 과다). 징후 = train loss는 계속 감소하는데 test loss는 감소하지 않음. 대책 = Regularization, Dropout, Data Augmentation
- 관련: Regularization, Dropout, Data Augmentation

### Batch Normalization (배치 정규화, BN)
- 정의: 각 층에 들어가는 값을 배치 단위로 **평균 0, 분산 1**로 표준화하고, 학습되는 조절값 **γ(감마), β(베타)**로 다시 조정하는 층
- 시험 포인트: ① 위치 = **선형층(FC/Conv) 뒤, 활성화 함수 앞** ② 효과 = gradient 흐름 안정화, 더 큰 learning rate 사용 가능, 초기값 영향 감소 ③ **학습 시엔 배치 통계, 추론 시엔 학습 중 기록한 이동평균 사용** (train/eval 모드 구분이 필요한 이유)
- 관련: model.train/eval, Standardization

### Dropout (드롭아웃)
- 정의: **학습 중** forward 때마다 무작위로 일부 뉴런의 출력을 0으로 만드는 기법. 특정 뉴런 의존을 막음
- 시험 포인트: ① 여러 부분 네트워크를 학습시키는 **Ensemble(앙상블) 효과** ② **추론 시엔 모든 뉴런 사용** ③ 파이토치 nn.Dropout(p) — p는 확률
- 관련: Inverted dropout, Ensemble, model.train/eval

### Inverted dropout (인버티드 드롭아웃)
- 정의: 추론 때 해야 할 크기 보정을 **학습 때 미리**(살아남은 값을 1/p배로 키워서) 처리하는 방식. 덕분에 추론 코드는 보정 없이 그대로
- 시험 포인트: "보정을 학습 쪽으로 옮긴 dropout" 한 줄
- 관련: Dropout

### Ensemble (앙상블)
- 정의: 여러 모델의 판단을 합치는 기법. Dropout이 매번 다른 부분 네트워크를 학습시키는 것이 앙상블과 유사한 효과
- 관련: Dropout

### Data Augmentation (데이터 증강)
- 정의: **라벨은 그대로 두고 입력만 변형**해서 학습 데이터 수를 늘리는 기법. 과적합의 정공법 대책
- 시험 포인트: 기본 5종 = **Crop(자르기), Translation(이동), Rotation(회전), Stretching(늘리기), Brightness(밝기)**. 파이토치에선 transforms의 Random~ 계열
- 관련: Mixup, Cutout, CutMix, Overfitting

### Mixup (믹스업)
- 정의: 두 사진을 반투명하게 **섞고, 라벨도 같은 비율로 섞는** 증강 기법 (개 0.5 / 고양이 0.5)
- 관련: Cutout, CutMix

### Cutout (컷아웃)
- 정의: 사진의 일부를 **검게 가리는** 증강 기법. 물체 일부가 가려져도(occlusion) 잘 인식하게 함. 라벨은 그대로
- 관련: Mixup, CutMix

### CutMix (컷믹스)
- 정의: 사진 일부를 **다른 사진의 조각으로 교체**하고, 라벨은 **면적 비율**로 섞는 증강 기법 (개 0.6 / 고양이 0.4)
- 관련: Mixup, Cutout

### Regularization / L2 (정규화)
- 정의: 모델이 과도하게 복잡해지는 것을 억제하는 기법의 총칭. L2는 loss에 파라미터 제곱합을 더해 가중치가 커지는 것을 벌점 처리
- 관련: Overfitting, Dropout

### Hyperparameter (하이퍼파라미터)
- 정의: 학습으로 정해지는 값이 아니라 **개발자가 직접 정하는 설정값** — learning rate, batch size, epoch 수 등
- 시험 포인트: "학습되는 파라미터(가중치)"와의 구분이 출제 포인트
- 관련: Grid search, Learning rate

### Grid search (그리드 서치)
- 정의: 하이퍼파라미터 후보들을 정해놓고 **모든 조합을 전부 학습해보며** 최고 조합을 찾는 탐색법
- 관련: Hyperparameter

### 학습 루프 (Training loop) — zero_grad / backward / step
- 정의: 한 배치를 처리하는 5단계. **① optimizer.zero_grad()**(gradient 초기화 — 누적 방지) → **② outputs = model(x)**(forward, 예측) → **③ loss = criterion(outputs, y)**(채점) → **④ loss.backward()**(gradient **계산만**) → **⑤ optimizer.step()**(파라미터 **실제 갱신**)
- 시험 포인트: 순서 문제 + backward(계산)와 step(갱신)의 역할 구분
- 관련: Gradient Descent, Adam

### model.train() / model.eval() (모드 전환)
- 정의: 학습 모드/추론 모드 선언. **동작이 바뀌는 층은 Dropout과 BatchNorm 둘뿐**
- 시험 포인트: "eval() 시 동작이 바뀌는 층은?" — Dropout(전부 켜짐), BatchNorm(이동평균 사용)
- 관련: Dropout, Batch Normalization, 추론

### 추론 (Inference, 테스트, 평가)
- 정의: 학습이 끝난 모델이 **예측만 하는** 국면. 학습(가중치 수정 중)의 반대말. 추론=테스트=평가=실전 사용, 전부 같은 뜻
- 관련: model.train/eval

# 7일차 — 모델 평가와 Convolution 연산

### Accuracy (정확도)
- 정의: 전체 예측 중 맞춘 비율 = (TP+TN) ÷ 전체
- 시험 포인트: **클래스 불균형에서 왜곡됨** — 암환자 1/정상 999 데이터에서 무조건 "정상"만 답해도 99.9%. 그래서 Precision/Recall이 필요
- 관련: Precision, Recall, Confusion Matrix

### Confusion Matrix (혼동 행렬)
- 정의: 예측 결과를 (실제 클래스 × 예측 클래스) 표로 정리한 것. 다중 클래스면 N×N 표
- 시험 포인트: c(i,j) = "실제 i인 데이터를 j로 예측한 개수". 대각선이 정답
- 관련: TP/FP/FN/TN

### TP / FP / FN / TN
- 정의: **TP**(True Positive) = 양성 예측·실제 양성(제대로 잡음) / **FP**(False Positive) = 양성 예측·실제 음성(**오탐**) / **FN**(False Negative) = 음성 예측·실제 양성(**놓침**) / **TN** = 음성 예측·실제 음성
- 관련: Precision, Recall

### Precision (정밀도)
- 정의: **양성이라고 예측한 것 중** 실제 양성의 비율 = TP ÷ (TP + FP). "말한 것에 책임" — 오탐이 적은가
- 관련: Recall, F1

### Recall (재현율, TPR)
- 정의: **실제 양성 중** 양성으로 잡아낸 비율 = TP ÷ (TP + FN). "있는 걸 다 찾기" — 놓침이 적은가
- 시험 포인트: True Positive Rate(TPR)와 같은 것
- 관련: Precision, ROC

### Threshold (임계값)
- 정의: 모델 출력(확률)을 양성/음성으로 가르는 기준선
- 시험 포인트: **임계값을 올리면 Precision↑ Recall↓, 내리면 Recall↑ Precision↓ — Trade-off 발생.** 둘을 동시에 올릴 수 없음
- 관련: Precision, Recall, PR Curve

### F1 (F1 점수)
- 정의: Trade-off 관계인 Precision과 Recall을 하나로 합친 **조화 평균** = 2PR ÷ (P+R)
- 관련: Precision, Recall

### PR Curve / AUC-PR
- 정의: 임계값을 전부 훑으며 (Recall, Precision) 점을 찍은 곡선(PR Curve)과 그 아래 면적(AUC-PR)
- 시험 포인트: AUC-PR은 **양성을 더 중요하게** 다룸 → 양성이 희귀하지만 중요한 문제(암 검사)에 적합
- 관련: ROC, AUC-ROC

### ROC / TPR / FPR / AUC-ROC
- 정의: 임계값을 훑으며 (FPR, TPR) 점을 찍은 곡선(ROC)과 그 아래 면적(AUC-ROC). TPR = TP÷(TP+FN), FPR = FP÷(TN+FP)
- 시험 포인트: **완전 랜덤 모델 = 0.5, 완벽한 모델 = 1.** 양성/음성을 **동등하게** 다루고 클래스 불균형에도 왜곡 없음
- 관련: PR Curve, Recall

### Macro-average (매크로 평균)
- 정의: 클래스별로 지표를 구한 뒤 **단순 평균**. 모든 클래스를 동등하게 취급 (희귀 클래스도 한 표)
- 관련: Micro-average

### Micro-average (마이크로 평균)
- 정의: 모든 클래스의 TP/FP 등을 **먼저 합산**한 뒤 하나의 표로 지표 계산
- 시험 포인트: **개수가 많은 클래스의 영향을 크게 받음** (다수 클래스가 지배)
- 관련: Macro-average

### Convolution (컨볼루션, 합성곱 연산)
- 정의: 작은 필터(도장)를 이미지 위에서 한 칸씩 밀며, 위치마다 "필터 무늬와 얼마나 닮았나" 점수를 재는 연산
- 시험 포인트: 등장 이유 = 픽셀 통째 비교는 위치·회전 변형에 실패하지만, **작은 조각(patch) 단위 패턴은 공유되므로** 국소 패턴 매칭으로 인식
- 관련: Filter, Feature map, CNN

### Filter / Kernel (필터, 커널)
- 정의: 찾고 싶은 패턴을 정의한 작은 숫자표(예: 3×3 세로선 패턴). 도장에 비유
- 시험 포인트: ① 필터 = FC layer의 weight 역할(학습으로 정해짐) ② **필터의 depth(겹수) = 입력의 depth** ③ **출력의 depth = 필터 개수** ④ kernel_size = 도장 크기
- 관련: Convolution, Channel

### Feature map / Activation map (특징 지도)
- 정의: 필터 하나를 이미지 전체에 밀며 찍어 만든 점수 지도. "이 패턴이 어디에 얼마나 있나"를 나타냄
- 관련: Convolution, Filter

### Receptive field (수용 영역)
- 정의: 출력의 한 칸이 입력에서 "보는" 범위. 3×3 필터 한 층이면 3×3
- 시험 포인트: **3×3 conv를 두 층 쌓으면 receptive field가 5×5** — 층을 쌓을수록 더 넓은 패턴을 봄
- 관련: Stacking, CNN

### Channel / Depth (채널, 겹)
- 정의: 데이터가 **몇 겹(장)짜리인가**. 컬러 이미지 = R/G/B 3겹, conv 통과 후 = 필터 개수만큼의 점수 지도 겹
- 시험 포인트: 입력 채널과 Conv2d의 in_channels가 일치해야 함. 출력 채널 = out_channels(필터 수). 채널은 나누기 대상이 아님(교체만 됨)
- 관련: Filter, Conv2d

# 8일차 — CNN 조립

### Stacking (Convolution 층 쌓기)
- 정의: 큰 필터 하나 대신 **작은 필터(3×3)를 여러 층 겹치는** 설계
- 시험 포인트: 이유 = 같은 패턴 검출 효과 + **파라미터 절약**(큰 필터는 파라미터 폭발 → 과적합). 3×3 두 층 = receptive field 5×5
- 관련: Receptive field, CNN

### Weight sharing / Conv와 FC의 관계
- 정의: Convolution layer는 **FC layer의 특수한 경우** — 같은 필터(가중치)를 모든 위치에서 재사용(공유)하고 나머지는 0인 희소한 FC층
- 시험 포인트: 그래서 FC의 backpropagation이 그대로 적용되고, 행렬곱 형태라 GPU에 최적
- 관련: Filter, CNN

### 비선형성 (Activation의 필요성, conv에서)
- 정의: 활성화 함수 없이 conv를 여러 층 쌓으면 전체가 **하나의 선형 계산**으로 뭉개짐. 층 사이에 ReLU 등이 필수
- 관련: ReLU, Stacking

### Padding / Zero padding (패딩)
- 정의: conv를 하면 크기가 줄어드는 것(출력 = 입력 − kernel_size + 1)을 막으려고 **테두리에 0을 두르는** 것
- 시험 포인트: **크기 유지 조건: padding = (kernel_size − 1) ÷ 2** (kernel 3이면 padding 1, kernel 5면 padding 2). padding 1 늘 때마다 출력 크기 2 증가
- 관련: Conv2d, Stride

### Stride (스트라이드)
- 정의: 필터(도장)를 **몇 칸씩 옮기며** 찍는가의 보폭
- 시험 포인트: **stride=2면 출력 크기 절반** (건너뛰며 찍으니까). stride=1이면 크기 영향 없음
- 관련: Padding, Conv2d

### Pooling / Max pooling (풀링)
- 정의: 이미지를 구역(보통 2×2)으로 나눠 구역마다 **최댓값 1개만** 남기는 연산. "세부 위치 → 개략적 위치"로 의도적으로 뭉갬
- 시험 포인트: ① 해상도 절반, **채널은 그대로** ② **학습되는 파라미터 없음** ③ 위치가 조금 변해도 인식 유지 효과
- 관련: CNN, Stride

### Flatten (플래튼)
- 정의: 2차원 특징 지도들을 **한 줄 벡터로 펼쳐서** FC층(분류기)에 넘겨주는 어댑터
- 관련: CNN, FC layer

### CNN (Convolutional Neural Network)
- 정의: **Conv 층들(특징 추출) + FC 층(분류)**을 쌓아 만든 모델. 전형 구조: [Padding→Conv→ReLU]×n → Pooling → ... → Flatten → FC → Softmax
- 시험 포인트: ① 학습 = forward(cross entropy) → backprop → gradient descent 그대로. 갱신 대상 = 필터와 FC 가중치(pooling/flatten엔 파라미터 없음) ② **적합한 데이터 = 인접 feature가 관련 있는 것(이미지, 소리, 텍스트)** ③ **부적합 = 행·열 바꿔도 유효한 표(테이블) 데이터**
- 관련: Convolution, Pooling, Flatten

### LeakyReLU (리키렐루)
- 정의: ReLU의 음수 구간에도 **작은 기울기**를 남겨둔 변형. Dead ReLU 문제 보완
- 관련: ReLU, Dead ReLU

### nn.Conv2d (파이토치 conv 층)
- 정의: `nn.Conv2d(in_channels, out_channels, kernel_size, stride, padding)`
- 시험 포인트(출력 shape 3단계): ① 장수 그대로 ② 채널수 = out_channels로 교체 ③ 크기 = padding이 (kernel_size−1)÷2이고 stride 1이면 그대로, stride 2면 절반, padding 없으면 크기 − kernel_size + 1
- 관련: Channel, Padding, Stride

# 9일차 — RNN과 언어 모델

### RNN (Recurrent Neural Network, 순환 신경망)
- 정의: 가변 길이의 **순서(sequence) 데이터**를 처리하는 구조. 매 time step마다 "새 기억 = 함수(이전 기억, 새 입력)"을 반복
- 시험 포인트: **모든 time step에서 같은 함수·같은 파라미터를 재사용(공유)**. 활성화 함수는 주로 tanh
- 관련: Hidden state, LSTM

### Hidden state (히든 스테이트, 은닉 상태)
- 정의: "지금까지 읽은 내용의 요약 메모". 매 step 갱신되어 다음 step으로 전달됨
- 관련: RNN, Cell state

### Rolled / Unrolled RNN (접힌/펼친 표현)
- 정의: 같은 RNN을 **자기 루프 화살표로 접어 그린 것(Rolled)**과 **시간축으로 펼쳐 체인처럼 그린 것(Unrolled)**. 동일한 것의 두 표현
- 관련: RNN

### RNN의 입출력 형태 (one-to-many 등)
- 정의/시험 포인트(매칭 문제로 출제): **one-to-many** = 이미지 캡셔닝(이미지→설명문) / **many-to-one** = 감정 분류(문장→긍정·부정) / **many-to-many(다 읽고 생성)** = 기계 번역 / **many-to-many(즉시 출력)** = 언어 모델, 실시간 비디오 분류
- 관련: RNN, Seq2Seq

### Language Model (언어 모델, LM)
- 정의: 지금까지의 글을 보고 **다음 글자(단어)를 확률로 예측**하는 모델
- 시험 포인트: ① 학습 = 입력을 한 칸 민 것이 정답(next token) + cross entropy ② **생성(추론) 시엔 방금 출력한 것을 다음 입력으로 되먹임** ③ 문장 시작/끝 표시 토큰 = **\<sos\> / \<eos\>**
- 관련: One-hot, BPTT, Seq2Seq

### One-hot encoding (원핫 인코딩)
- 정의: 글자를 "해당 자리만 1이고 나머지는 0인 벡터"로 표현하는 방식
- 시험 포인트: 이유 = 글자를 1, 2, 3 같은 번호로 주면 **없는 크기·순서 관계가 생기기 때문**. 글자들은 서로 독립적인 categorical 변수
- 관련: Language Model

### BPTT (Backpropagation Through Time)
- 정의: 시퀀스 전체에 대해 **시간을 거슬러** backpropagation을 수행하는 것. 뒤쪽 loss일수록 gradient가 앞 시점까지 길게 흘러감
- 시험 포인트: 문제점 = 긴 시퀀스에서 계산 비용·메모리가 큼 → Truncated BPTT로 해결
- 관련: Truncated BPTT, Vanishing gradient

### Truncated BPTT (잘라낸 BPTT)
- 정의: 시퀀스를 **구간(chunk) 단위로 잘라** 구간 안에서만 backpropagation. 단, **hidden state는 구간을 넘어 유지**하며 forward는 이어감
- 관련: BPTT

### Exploding gradient (그래디언트 폭발)
- 정의: backpropagation에서 같은 가중치가 시점마다 반복해 곱해질 때, 그 값의 **절대값이 1보다 크면** gradient가 기하급수적으로 커지는 현상
- 시험 포인트: |값|>1 → 폭발, |값|<1 → 소실. 행렬 버전은 **eigenvalue(고유값)의 절대값** 기준
- 관련: Vanishing gradient, RNN

### Vanishing gradient (그래디언트 소실)
- 정의: 반복 곱해지는 값의 절대값이 1보다 작아 gradient가 0으로 사라지는 현상. **RNN이 긴 문장의 앞부분을 학습 못 하는 원인**
- 시험 포인트: sigmoid 포화(5일차)와 RNN 반복 곱(9일차) 두 맥락에서 등장. 해결책 = LSTM (+ 10일차의 Attention도 지름길 제공)
- 관련: Exploding gradient, LSTM, Sigmoid

### LSTM (Long Short-Term Memory)
- 정의: **cell state라는 별도의 기억 통로**와 게이트 3개를 더해 장기 기억 문제를 해결한 RNN 개량형
- 시험 포인트: 게이트 3개의 역할 — **Forget gate**(이전 기억을 얼마나 지울지), **Input gate**(새 정보를 얼마나 쓸지), **Output gate**(기억을 얼마나 내보낼지). 게이트는 0~1 사이 값(sigmoid)
- 관련: Cell state, GRU, Vanishing gradient

### Cell state (셀 스테이트)
- 정의: LSTM 위쪽을 지나는 **덧셈 기반의 정보 고속도로**. 곱셈 변형을 강제로 거치지 않아 **정보와 gradient가 왜곡 없이 먼 과거까지 흐름** → 장기 기억(long-term dependency) 해결
- 관련: LSTM, Hidden state

### GRU (Gated Recurrent Unit)
- 정의: LSTM의 경량판. **cell state와 hidden state를 하나로 통합**하고, forget/input 게이트를 하나로 묶음(합이 1이 되게)
- 시험 포인트: "LSTM보다 파라미터 적고 성능 비슷"
- 관련: LSTM

# 10일차 — Seq2Seq와 Attention

### Seq2Seq (시퀀스 투 시퀀스)
- 정의: **Encoder(입력 문장을 읽어 압축) + Decoder(받아서 출력 문장을 한 토큰씩 생성)**의 2단 구조. 기계 번역, 대화 시스템, question answering에 사용
- 시험 포인트: 가변 길이 입력/출력 처리 가능. 약점 = Bottleneck problem
- 관련: Encoder, Decoder, Bottleneck, Attention

### Encoder (인코더)
- 정의: 입력 문장을 순서대로 읽어 **고정 크기 latent vector로 압축**하는 쪽
- 관련: Seq2Seq, Latent vector

### Decoder (디코더)
- 정의: 인코더의 요약을 받아 출력 문장을 **한 토큰씩 생성**하는 쪽. \<sos\>로 시작, 방금 출력을 다음 입력으로 되먹임, \<eos\>가 나오면 종료
- 관련: Seq2Seq, Teacher forcing

### Latent vector (잠재 벡터, context vector)
- 정의: 인코더가 입력 전체를 압축해 담은 **고정 크기 벡터**. 디코더의 첫 상태로 전달됨
- 관련: Bottleneck

### Bottleneck problem (병목 문제)
- 정의: 입력이 아무리 길어도 **고정 크기 latent vector 하나**에 다 담아야 해서 긴 입력의 정보가 손실되는 Seq2Seq의 한계
- 시험 포인트: **Attention이 이것을 해결** — 디코더가 벡터 하나에 의존하지 않고 입력을 직접 참조
- 관련: Latent vector, Attention

### Attention (어텐션)
- 정의: 디코더가 **매 토큰을 생성할 때마다**, 인코더의 hidden state들 전체 중 "지금 필요한 부분"에 가중치를 줘서 정보를 가져오는 장치
- 시험 포인트(동작 3단계): ① 디코더 상태와 인코더 각 상태의 관련도 **점수(score)** 계산 ② **Softmax**로 확률 분포화 ③ 분포를 가중치로 인코더 상태들의 **가중합(weighted sum)** = attention 출력 → 디코더 상태와 이어 붙여(concatenation) 예측
- 시험 포인트(장점 4개): **병목 해소** / **성능 향상** / **먼 과거로 가는 gradient 지름길**(vanishing 완화) / **해석 가능**(어디를 봤는지 시각화 가능)
- 관련: Bottleneck, Alignment, Seq2Seq

### Alignment (얼라인먼트, 단어 정렬)
- 정의: 번역에서 소스 단어와 타깃 단어의 대응 관계 (예: "간다"↔"go"). Attention 분포를 시각화하면 모델이 **가르쳐주지 않아도 스스로 학습한** alignment가 보임
- 시험 포인트: 영어(SVO)↔한국어(SOV)의 어순 차이를 attention이 스스로 처리
- 관련: Attention

### Teacher forcing (티처 포싱)
- 정의: **학습 시** 디코더에 자신의 (틀렸을 수도 있는) 예측 대신 **정답 토큰을 다음 입력으로 주는** 기법. 한 번의 오답이 뒤 전체를 망치는 것을 방지
- 관련: Decoder, Seq2Seq

### Perplexity (퍼플렉시티, PPL)
- 정의: 언어 모델의 평가 지표. **낮을수록 좋음**
- 시험 포인트: 실습에서 attention 추가로 42.7 → 24.5로 개선(성능 향상의 수치 증거)
- 관련: Language Model, Attention

### \<sos\> / \<eos\> (문장 시작/끝 토큰)
- 정의: **\<sos\>** = Start of Sentence(생성 시작 신호), **\<eos\>** = End of Sentence(생성 종료 신호)
- 관련: Decoder, Language Model
