## 주요 기능 3

1. **아침 픽업 예약** — 10분 슬롯(슬롯당 3잔)을 서버가 전 고객 기준으로 관리. 이름+전화로 내 예약 확인·취소까지. 규칙(영업시간·휴무일·슬롯 상한·입력 형식)은 전부 서버가 강제 — 폼을 우회한 API 호출도 막힌다.
2. **원두·디저트 주문** — 상품 담기 → 장바구니(수량·합계) → 주문 접수 → 새로고침에도 유지되는 최근 주문. 접수·취소·주문 순간 **사장 슬랙에 즉시 알림**.
3. **사장 운영 도구** — 로그인 전용 관리 화면(예약/주문 탭, 상태 처리), 방문·전환 측정(Umami), 1개월 개인정보 자동 파기(cron).
