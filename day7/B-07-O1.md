# B-07-O1 — 모닝브루 사용자 흐름도 (Mermaid)

> 관리번호: **B-07-O1** (기초반 · 7일차 · 산출물 1) · 작성일: 2026-07-14
> 근거: 실제 구현된 통합 페이지(B-05-O1/B-06-O1)의 동작 그대로 — 진입·행동·결과·분기(오류 경로 포함)
> 렌더 확인: 로컬 Mermaid 렌더 + 캡처 (`B-07-O1.png`) / mermaid.live 에서도 동일 확인 가능

```mermaid
flowchart TD
    A(["진입: 모닝브루 페이지 방문"]) --> B["행동: 메뉴·특징 확인"]
    B --> C["행동: 예약 폼 작성<br/>(이름·연락처·메뉴·수량·날짜·시간)"]
    C --> D{"분기: 필수값 입력<br/>+ 개인정보 동의?"}
    D -- "아니오" --> E["오류: 경고창 + 빈 칸 표시"]
    E --> C
    D -- "예" --> F{"분기: 픽업 슬롯<br/>남아 있나? (10분당 3잔)"}
    F -- "가득 참" --> G["오류: 마감 안내<br/>(마감 슬롯은 선택 자체가 차단됨)"]
    G --> C
    F -- "여유 있음" --> H{"분기: 확인창(confirm)<br/>예약 내용 확정?"}
    H -- "취소" --> C
    H -- "확인" --> I["처리 중 (버튼 비활성)"]
    I --> J(["결과: 접수 완료<br/>완료 메시지 + localStorage 저장"])

    J -.-> K["행동: 내 예약 확인<br/>(이름+연락처 조회)"]
    K --> L{"분기: 예약 존재?"}
    L -- "없음" --> M["안내: 없는 예약"]
    L -- "있음" --> N["결과: 내 예약 목록 표시"]
    N --> O{"분기: 접수 상태?"}
    O -- "예 (접수)" --> P["행동: 직접 취소 가능<br/>→ 슬롯 반납"]
    O -- "아니오 (확정 이후)" --> Q["안내: 전화 문의"]

    J -.-> R["관리자: 예약 목록에서 확인"]
    R --> S["상태 변경: 접수 → 확정 → 픽업완료"]
    S --> T(["결과: 매장 픽업 완료"])
```

## 흐름 구성 요약

| 요소 | 내용 |
|---|---|
| **진입** | 페이지 방문 (검색·공유 링크) |
| **행동** | 메뉴 확인 → 폼 작성 → (접수 후) 내 예약 확인 |
| **분기 4개** | ①필수값·동의 ②슬롯 여유 ③confirm 확정 ④(조회 시) 예약 존재·상태 |
| **오류 경로** | 빈 칸 경고 / 슬롯 마감 / 없는 예약 — 모두 폼·안내로 복귀 (막다른 길 없음) |
| **결과** | 접수 완료(저장) → 관리자 확정 → 매장 픽업 완료 |
