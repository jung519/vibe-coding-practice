## 실전 모의고사 (20문제)

### A. 수식 인지 유형 (수식 보고 이름/의미 고르기)

**1.** 다음 수식이 정의하는 것은?  **H(X) = −Σ p(x) log p(x)**
   ① Cross entropy  ② Entropy  ③ KL divergence  ④ Mutual information

**2.** 다음 수식이 정의하는 것은?  **−E_{x~p(x)}[log q(x)]**
   ① Entropy  ② KL divergence  ③ Cross entropy  ④ Mutual information

**3.** 다음 수식의 이름은?  **σ(z) = 1 / (1 + e^(−z))**
   ① Softmax  ② ReLU  ③ Hard thresholding  ④ Sigmoid (Logistic function)

**4.** 다음 수식은 무엇을 계산하는가?  **e^(z_c) / Σ_c e^(z_c)**
   ① Softmax (logit → 확률 변환)  ② Sigmoid  ③ MSE  ④ Gradient

**5.** 다음 수식이 정의하는 것은?  **lim_{ε→0} [f(x+ε) − f(x)] / ε**
   ① 적분  ② 극한  ③ 미분(도함수)  ④ 기대값

**6.** 다음 갱신 규칙의 이름은?  **w := w − α · ∂L/∂w**
   ① Gradient descent  ② Forward propagation  ③ Broadcasting  ④ Normalization

**7.** 다음 관계식에서 빈칸에 들어갈 것은?  **D_KL(P‖Q) = CE(P,Q) − ( ? )**
   ① H(Q)  ② H(P)  ③ I(P,Q)  ④ 0

## 정답 및 한 줄 해설

1. **②** Entropy — "-Σ p log p"는 엔트로피의 정의식. (p 하나만 등장하면 entropy)
2. **③** Cross entropy — p에서 뽑아서 q로 놀람. **p와 q 두 개가 등장하면 CE 또는 KL**인데, log 안에 q만 있으면 CE.
3. **④** Sigmoid — 0~1로 눌러주는 S자. "Logistic function"도 같은 말.
4. **①** Softmax — 지수화 후 합으로 나누기 = 점수를 합 1인 확률로.
5. **③** 미분 — ε을 0으로 보내는 변화율. 1일차 첫 수식.
6. **①** Gradient descent — "gradient의 반대 방향으로 α(learning rate)만큼 이동"을 식으로 쓴 것.
7. **②** H(P) — KL = CE − H(P). 그래서 CE 최소화 = KL 최소화.
8. **②** 커진다 — 정보량 = 놀라움 = -log P.
9. **③** Uniform — 뭐가 나올지 전혀 모르는 분포.
10. **④** 대칭적이다 — KL은 **비**대칭. 나머지는 전부 맞는 성질.
11. **①** -log 0.6 — 이번엔 정답(강아지)이 최대 확률과 같은 자리. 항상 "정답 자리의 확률"에 -log.
12. **③** Gradient.
13. **②** AI ⊃ ML ⊃ DL.
14. **③** XOR — 직선 하나로 분리 불가. MLP로 해결.
15. **①** 선형 함수 — 직선을 아무리 합성해도 직선.
16. **②** Linear layer — 행렬곱(선형 변환)을 하는 층이라서.
17. **③** NLL loss — 정답 확률에 -log. one-hot cross entropy와도 동일.
18. **②** 곱셈 — "책임 = 자체 민감도 × 뒤에서 온 책임" (chain rule).
19. **①** 덧셈 = 분배기(distributor), 곱셈 = 교환 곱(swap multiplier).
20. **②** loss.backward() — step()은 업데이트, zero_grad()는 초기화. 셋의 역할 구분이 출제 포인트.

## 수식 ↔ 이름 매칭표 (암기용 — 이것만 외우면 A유형 전부 커버)

| 수식에 이게 보이면                          | 답                                        |
| ----------------------------------- | ---------------------------------------- |
| −Σ **p** log **p** (분포 하나)          | **Entropy** H(X)                         |
| −Σ **p** log **q** (분포 둘, log 안에 q) | **Cross entropy** CE(P,Q)                |
| E[log(**p/q**)] (log 안에 비율)         | **KL divergence**                        |
| H(X) + H(Y) − H(X,Y)                | **Mutual information** I(X,Y)            |
| 1/(1+e^(−z))                        | **Sigmoid** (= Logistic function)        |
| e^z / Σe^z                          | **Softmax**                              |
| lim (f(x+ε)−f(x))/ε                 | **미분** (도함수 정의)                          |
| [∂f/∂x₁, ∂f/∂x₂, …] 벡터              | **Gradient** ∇f                          |
| ∂²f/∂xᵢ∂xⱼ 행렬                       | **Hessian**                              |
| w := w − α·∂L/∂w                    | **Gradient descent** (α = learning rate) |
| f(w₀ + w₁x₁ + w₂x₂)                 | **Perceptron**                           |
| −log p̂(정답)                         | **NLL = Softmax loss = CE loss**         |

구분 요령 딱 하나: **분포가 하나면 Entropy, 둘인데 log 안에 q만 있으면 CE, log 안에 p/q 비율이면 KL.**
