# PRD lite v1 — 모닝브루

> 관리번호: **B-02-O1** · 기초반 2일차 산출물
> 근거 자료: 시장조사(B-02-R1) · 경쟁사 분석(B-02-R2)
> **주력 타깃**: 출근길 직장인 · **예약 수단**: 웹 문의·예약 폼 · **핵심 기능(★)**: 아침 픽업 예약

## 1. 문제 *(가설 — 검증 대상)*
출근길 직장인은 아침에 커피를 사려면 프랜차이즈 줄에 서야 해 **출근 시간에 쫓기고, 대기 시간을 예측할 수 없다**고 가정한다. 그렇다고 편의점 커피는 품질이 아쉽다.
> 이 불편의 실재 여부는 시장조사(B-02-R1) Q4의 검증 대상이다.

## 2. 타깃
**망원역 2번 출구 인근으로 출근하는 30대 직장인** — 아침 8~9시, 시간에 쫓기며 품질 좋은 커피를 원하는 사람.
(모든 고객 ❌ / 재택·주민·카공족은 이번 범위 밖)

## 3. 가치 — 경쟁 대안과 다른 우리만의 해결책

경쟁 대안 분석(B-02-R2)의 **가정**에 따르면, 아래 대안들은 4가지를 동시에 채우지 못하는 것으로 보인다 *(경쟁사 속성은 미검증 가정)*:

| 경쟁 대안 | 못 채우는 부분(가정) |
|---|---|
| 대형 프랜차이즈 | 붐빔·대기, 골목의 편안함 없음 |
| 저가·무인 카페 | 품질·정성 부족 |
| 개인 감성 카페 | 아침에 안 열고, 픽업 개념 없음 |
| 편의점·배달 | 품질 낮거나, 배달비·지연 |

**→ 모닝브루의 차별화 가설:** **이른 아침(08시) + 직접 내린 품질 + 골목의 편안함 + 사전 픽업 예약.**
"줄 서지 않고 미리 주문해 픽업만" 하는 경험을 노린다. *(상권에서 "유일"한지는 실제 조사로 확인 전까지 단정하지 않는다.)*
> ✅ 08시 오픈·핸드드립 품질은 Day1 근거. / 🟡 경쟁 우위·수요는 검증 대상 가설.

## 4. 핵심 흐름
소개 페이지 방문 → 메뉴 확인 → **웹 폼으로 픽업 예약(메뉴·시간 선택)** → 매장에서 픽업

| ✅ 이번에 만들 것 | ⏳ 나중에 (이번 제외) |
|---|---|

| 메뉴 안내 | 멤버십·적립 |
| **아침 픽업 예약 폼 ★** | 전용 앱 |
| 공개 URL 배포 | 방문·매출 통계 |
